# Candidate Scorecard

A simple HR tool to rate job candidates fairly and compare them.

**Live demo:** https://wardaddyxe.github.io/candidate-scorecard/

## Features
- Rate 5 skills (1–5) with weights
- Auto score (%) and verdict: Strong hire / Consider / Not a fit
- Save and rank candidates (stored in your browser)
